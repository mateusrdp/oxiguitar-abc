# oxiguitar-abc

A placeholder for an ABC notation format plugin for [OxiGuitar](https://github.com/mateusrdp/oxiguitar), a free, open-source guitar tablature and score viewer, editor and player for Windows, macOS and Linux.

**This plugin isn't being built.** ABC support was dropped on 9 November 2026, and this repository is kept only as the empty scaffold it was. To bring an ABC tune into OxiGuitar today, convert it to MusicXML (with abc2xml or EasyABC, for example) and open that with the MusicXML plugin.

## What ABC is

[ABC notation](https://abcnotation.com/) is a way of writing music as plain text, devised by Chris Walshaw in the 1990s. A tune is a few header lines (title, metre, key) followed by its notes as letters: `C D E F | G2 G2 |`. It is easy to type in an email or a forum post, which made it the format of choice for folk and traditional tunes, and tens of thousands of tunes are shared that way.

## What's here

Nothing that runs: the repository layout, CI, licence and contribution rules every OxiGuitar plugin repository starts with. The user manual and the plugin developer guide live in the [OxiGuitar repository](https://github.com/mateusrdp/oxiguitar). If you would like to see ABC support come back, say so in [OxiGuitar's Discussions](https://github.com/mateusrdp/oxiguitar/discussions): anyone can write a format plugin with the SDK.
